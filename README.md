# Range Sum Queries

A simple Python solution that adds the elements within a range of an array.

[Range_Sum_Queries_Simple.py](Range_Sum_Queries_Simple.py) uses the array `[2, -1, 7, 2, -3, -2, 4]` and loops through the selected range to calculate its sum.

Enter boundaries starting at index 0. The left boundary is included and the right boundary is excluded, with `0 <= l <= r <= 7`. For example, `l = 0` and `r = 3` gives **8**.
